# Desarrollador Full Stack

## Descripción

Buscamos una persona para incorporarse a nuestro equipo y participar en el diseño, desarrollo y mantenimiento de aplicaciones web.

## Requisitos

- Experiencia con JavaScript y Node.js
- Conocimientos de React y APIs REST
- Manejo de bases de datos relacionales (PostgreSQL o MySQL)
- Uso de Git en entornos colaborativos
- Conocimientos de Docker

## Se valorará

- TypeScript
- Experiencia con AWS
- Conocimientos de MongoDB
- Testing automatizado
